## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability within MediaFlow Proxy, please do NOT open a public issue.

Instead, please send an email to [mhdzumair@gmail.com](mailto:mhdzumair@gmail.com).

We will try to review and address the issue as soon as possible.
